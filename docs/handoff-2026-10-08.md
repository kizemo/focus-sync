## 4. 关键设计决策(改代码前必读)

### 4.1 插件源码只有一份,在 `dist/`

```
release/extension/dist/index.js   ← 唯一真相源,手工维护
```

**曾经存在一个 `extension/` 目录**(TypeScript + rollup),已于 2026-10-08 **删除**。
它是 **pre-v0.3.0 的 spawn 架构**(用 `sigma.binary` 亲自拉起 sidecar),
与当前 Scheduled Task 架构是**两条设计路线,不是新旧版本**。
用它构建会覆盖 `dist`,丢掉 v0.3.0 → v0.5.5 的全部修复。

恢复 TS 构建链是一项独立工程,必须单独立项。

### 4.2 三个 SendInput 闸门(BUG-1 安全修复)

`uia_inject.rs::dialog_still_foreground()`,在**两个** `SendInput` 调用点前各校验一次:

```
① IsWindow(Some(hwnd)).as_bool()      句柄还活着吗
② detector::is_file_dialog(hwnd)      结构上还是文件对话框吗(独立于 monitor)
③ state.foreground_dialog() == hwnd    monitor 说它在前台吗
```

**为什么必要**:monitor 检测对话框在前台,与 `SendInput` 真正发出之间隔着 ~300ms 的
UIA 扫描。用户在这期间切到别的应用,按键就会打到那里。
实测后果:路径被输入到聊天窗口并**回车发送了消息**。

**注意 ③ 依赖 monitor 状态;② 完全独立**,所以三条要一起用。

### 4.3 DIRECT-1:直接替换替代删除

原实现一次注入要发 290~340 个事件(`Ctrl+L` + `End` + **128× Backspace** + 逐字符输入)。
现在先只发 `Ctrl+L`(4 事件),再尝试 **UIA `SetValue` 直接设置地址栏内容**。

**必须有读回证明值替换上了才走这条路**,否则落回原来的按键路径。
最坏情况 = 和现在完全一样,不会静默失效。

`Ctrl+A` 已在 G-4 试过并失败(被文件列表截获),所以这是**不同的机制**。

### 4.4 DEDUP-1:/set_path 去重

`/set_path` 会跳过「`last_written_path` 已等于目标路径」的对话框。
原有的 `path_unchanged` 只比较 `state.current_path`,**不比较「这个对话框里已经写过什么」** ——
这是 2026-10-08 观察到「一次切回注入两遍」的根因。

### 4.5 焦点只由 monitor 线程发布

```
monitor 线程  spawn_blocking + GetMessageW/DispatchMessageW  → 有消息队列 ✅
HTTP 线程     std::thread::spawn                            → 无消息队列   ❌
```

`GetForegroundWindow()` 返回**调用线程**的前台窗口。HTTP 线程上调用不可靠,
曾导致每一次 `/set_path` 都被误判为「非前台」而延后。

**约定:前台状态一律由 monitor 写入 `AppState.foreground_dialog`,其他线程只读。**

## 8. 给新会话的三条最重要的经验

这些是 2026-10-07~08 两天、18 小时排障换来的,写在 agent 记忆里,这里再复述:

1. **先证明你的尺子没坏,再拿它量东西。**
   我用 ANSI 代码页读 UTF-8 日志,得出「中文路径 mojibake」假根因,还拿这份假数据去「验证」检测算法,算法完美工作,于是错误被确认。**用自己新写的工具验证自己基于该工具得出的结论 = 循环论证。**

2. **编译通过 ≠ 补丁生效。**
   `$t.Replace($anchor, ...)` 在锚点不匹配时是**静默 no-op**。同一天因此两次发布「编译过、66 个测试全绿、功能完全没修好」的版本。改完必须回读源码确认。

3. **先问用户一个 10 秒钟能回答的具体问题,而不是再推理一轮。**
   「地址栏里有没有出现过路径文本」——用户一句话回答了,我五轮日志推理没回答出来。

补充一条:**看到异常值就死盯异常值,是一种系统性偏误。**
我盯着 `HWND(0x0)` 断定「H1 永久失效」,而全量统计是**成功 48 次**。
定性任何观测之前,先看全量分布。
